# Автоматический коммит и пуш для всех проектов с .branches

Этот workflow для n8n автоматически находит все проекты (репозитории) в заданной директории, для каждого из них:
- Проверяет наличие незакоммиченных изменений через `git diff`;
- Генерирует осмысленное сообщение коммита (с заголовком и телом) с помощью LLM (OpenRouter);
- Выполняет `git add .`, `git commit -m "..." -m "..."` и `git push` во все указанные ремоуты и ветки, перечисленные в файле `.branches`.

---

## Структура проекта

- Все твои репозитории должны лежать в одной корневой папке (например, `/data/projects` внутри контейнера).
- В **корне каждого репозитория** должен лежать файл `.branches` в формате JSON:

```json
{
  "targets": [
    { "remote": "origin", "branch": "main" },
    { "remote": "gitlab", "branch": "master" }
  ]
}
```


## Значения по-умолчанию

1. Если файл пуст, предполагается, что существует origin/master
2. Если у ветки указан только remote, то ветка предполагается master
